1. Проблема и Продукт
Суть решения
  • Продукт: Веб-приложение для автоматической разметки действий на видео
  • Пользователи: ML-инженеры, CV-эксперты и разметчики данных
  • Решение: Уход от разметки с нуля (генерация черновика → быстрая правка)
Проблематика
  • Долго: 15–30 минут ручного труда на 1 короткий ролик
  • Дорого: разметка 1000 видео обходится в сотни часов
  • Боль: монотонное ручное выделение границ и подбор классов
Ценность для процесса
  • Скорость: 4–10 мин вместо 15–30 мин / ролик
  • Экономия: снижение затрат времени на ≥ 66%

UI (Frontend)
  • Роль: Интерактивный редактор
  • Суть: Быстрая визуальная оценка таймлайна, ручная корректировка (HITL) и экспорт
API (Backend)
  • Роль: Оркестрация и валидация
  • Суть: Связующее звено, строгая проверка JSON по контрактам (rules.json)
Pipeline (ML)
  • Роль: Поиск границ и классификация действий
  • Нарезка: Ансамбль (Motion, SAM3, V-JEPA) для генерации proposals границ без переобучения
  • Семантика: Open-set ranking (X-CLIP) для определения Action/Object на вырезанных сегментах

5. Итоги и План развития
Ключевой итог
Продукт сокращает время разметки на 66%. ML-инженеры быстрее обучают модели, сохраняя высокое качество данных.
Масштабирование (Бизнес)
  • Новые домены: кухня, сборка на конвейере, склад
  • Новые клиенты: интеграция в 3 CV-лаборатории (план на год)
Техническое развитие
  • Active Learning: ревью только шагов с низким confidence
  • Интеграции: прямая выгрузка в Label Studio и CVAT
