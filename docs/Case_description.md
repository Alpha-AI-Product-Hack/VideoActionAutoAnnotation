# Автоматическая разметка действий по видео

## Описание

### Продукт или процесс, к которому относится кейс

Кейс относится к процессу подготовки размеченных видеоданных для разработки систем компьютерного зрения и обучения роботов.

Сейчас специалист вручную просматривает каждое видео, делит происходящее действие на шаги и указывает для них временные границы, названия действий и связанные объекты. Такая работа необходима для подготовки видеодатасетов, но занимает значительное время.

Предлагаемое веб-приложение должно автоматически формировать первоначальную разметку ролика. После этого специалист проверяет результат, исправляет найденные ошибки и выгружает готовую разметку в JSON или CSV.

### В чём боль и сколько она стоит бизнесу сейчас

Для разработки систем компьютерного зрения и обучения роботов необходимы размеченные видеозаписи действий человека. Сейчас такую разметку специалист выполняет вручную: просматривает ролик, определяет отдельные шаги, отмечает их временные границы, подписывает действия и связанные с ними объекты.

Ручная обработка одного короткого ролика занимает 15–30 минут. При стоимости работы специалиста 2–4 тыс. рублей в час разметка тысячи роликов обходится примерно в 500 тыс.–2 млн рублей.

Предлагаемое решение должно автоматически создавать первоначальную разметку видео. Специалисту останется проверить результат, исправить найденные ошибки и выгрузить готовые данные. Автоматизация должна сократить время и стоимость разметки минимум в три раза.

### Кто пользователь решения и как он им пользуется

Пользователем решения может быть:

ML-инженер;
специалист по компьютерному зрению;
разметчик данных.

### Пользовательский сценарий

1. Пользователь загружает в веб-приложение короткое видео.
2. Система автоматически делит его на отдельные действия.
3. Для каждого действия определяются временные границы, тип действия и объект.
4. Система выбирает ключевой кадр для каждого шага.
5. Пользователь просматривает результат и при необходимости исправляет разметку.
6. После проверки готовая разметка выгружается в JSON или CSV.

Таким образом, решение не исключает специалиста из процесса. Оно подготавливает первоначальный вариант разметки и сокращает объём ручной работы.

### Постановка задачи и этапы работы

Разработать веб-приложение для автоматической разметки коротких видеозаписей действий человека.

### 1. Загрузка видео

Пользователь загружает видео продолжительностью до 30 секунд. Поддерживаются форматы MP4 и MOV с разрешением от 720p.

### 2. Разделение видео на действия

Система анализирует ролик и делит его на отдельные шаги

### 3. Определение действия и объекта

Для каждого действия определяются начало, конец, тип действия и объект.

### 4. Выбор ключевого кадра

Для каждого действия выбирается ключевой кадр, который наглядно представляет соответствующий шаг и может использоваться при просмотре или проверке разметки.

### 5. Проверка и исправление результата

Пользователь просматривает автоматически созданную разметку в интерфейсе. При необходимости он изменяет временные границы, тип действия, связанный объект или выбранный ключевой кадр.

### 6. Экспорт готовой разметки

После проверки пользователь выгружает результат в JSON или CSV. Экспорт должен содержать автоматически найденную и при необходимости исправленную информацию о шагах видео.

Для реализации разрешено использовать готовые модели и облачные API. С нуля необходимо собрать общую цепочку обработки видео, интерфейс редактирования разметки и экспорт данных.

### Что не входит в скоуп хакатона
- управление роботом;
- ROS и робототехнические симуляторы;
- построение трёхмерных траекторий;
- определение физических усилий и точных контактов;
- обучение большой модели с нуля;
интеграция с внутренними системами компании;
- промышленная нагрузка, роли пользователей и биллинг;
- поддержка действий за пределами заданного списка.

### Описание данных

Закрытые данные компания не предоставляет. Участники используют открытые наборы данных или могут самостоятельно снять 20–50 коротких роликов под задачу.

### Требования к видео

- формат MP4 или MOV;
- разрешение от 720p;
- продолжительность от 5 до 30 секунд;
- один человек в кадре;
- одно основное действие на ролик;
- отсутствие монтажных склеек и сложных производственных операций.

При самостоятельной съёмке нельзя использовать персональные или конфиденциальные данные. Если команда применяет готовые модели или внешние API, необходимо указать использованные сервисы и стоимость обработки.

Для финальной оценки используется одинаковый для всех команд скрытый набор из 8–12 роликов.

### Ограничения
в видео не должно быть монтажных склеек, нескольких одновременно работающих людей и сложных производственных операций;
разрешены готовые модели и внешние API, но команда должна указать используемые сервисы и стоимость обработки;
при съёмке нельзя использовать персональные или конфиденциальные данные.

## Ожидаемый результат

Работающее веб-приложение, которое демонстрирует полный цикл подготовки разметки короткого видео — от загрузки исходного файла до выгрузки проверенного результата.

В приложении должны быть реализованы все основные части исходной задачи:

- загрузка короткого видео;
- автоматическое разделение ролика на действия;
- определение начала и конца каждого действия;
- определение типа действия и связанного объекта;
- выбор ключевого кадра;
- временная шкала с найденными шагами;
- редактор автоматической разметки;
- экспорт результата в JSON или CSV.

Пользователь должен иметь возможность просмотреть автоматически созданную разметку, исправить ошибочные значения и выгрузить итоговый вариант без ручного заполнения результата с нуля.

Команда также предоставляет инструкцию по запуску проекта и несколько примеров обработки видео.

### Целевая метрика и что считаем успехом

#### Качество разделения видео
Step-level F1 должен составлять не менее 0,75. Метрика оценивает качество автоматического выделения отдельных действий.

Ошибка определения временных границ действия должна составлять не более 2 секунд.

#### Качество распознавания
Не менее 80 % действий и объектов должны быть определены правильно.

#### Корректность экспорта
Файлы JSON и CSV должны проходить проверку формата в 100 % случаев.

#### Состьость обработки
Автоматическая разметка одного ролика должна занимать не более 2 минут.

#### Сокращение ручной работы
Время работы пользователя с одним роликом должно сократиться минимум в 3 раза по сравнению с полностью ручной разметкой.
